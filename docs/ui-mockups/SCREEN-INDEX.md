# Medmack UI concepts

Image-generation-only visual exploration. No software or account connection is being implemented. The pasted brief is the product source; all projects, prices, customer facts and activity are illustrative.

72 screens and dialogs, each imagined separately as one PC mockup and one phone mockup: 144 individual images. The phone is recomposed, not a scaled desktop screen. Built-in image generation was used; exact prompts are in GENERATION-PROMPTS.json.

## Visual direction

Impeccable Operate principles: clear task hierarchy, restrained state color, readable type, evidence near decisions, visible human approval, recoverable errors and company-specific configuration. Light surfaces reflect document-heavy engineering review. Petroleum teal identifies actions; amber marks review. No collage or multi-device images.
