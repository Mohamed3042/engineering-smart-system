# Medmack UI concepts — version 2

79 screen states, each separately imagined on desktop and phone: **158 individual PNGs**. Every image contains one device and one active screen or dialog. No collages.

Version 2 refines 22 existing states and adds 7 states. The remaining 50 states retain their original imagery. [Refinement notes](REFINEMENT-NOTES.md) explain the workflow changes. Exact generation and edit prompts are in [GENERATION-PROMPTS.json](GENERATION-PROMPTS.json).

These are generated visual concepts, not working software or engineering validation. Customer/project examples, technical values, prices and activity are fictional. Different states illustrate different moments in a workflow. Filled price cells represent sample manual pricing; initial real quotations require human-entered prices.

The identity remains light surfaces, charcoal text, deep teal actions and restrained review colors. Phone layouts are composed separately from desktop layouts.
