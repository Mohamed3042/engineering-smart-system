## Interpretation

All customers, people, projects, dates, technical values and prices are fictional examples. Prices shown in filled quotation cells illustrate a manually priced draft; they are not values an AI should invent. A source-confirmed requirement is not an approved design. Different mockups illustrate different points in a workflow.

The PNGs were visually reviewed and corrected for material workflow, text and layout inconsistencies. Minor raster glyph defects may remain; implement labels and addresses from structured data, not by OCR-copying the images. They remain generated raster concepts, not editable components, working controls, accessibility testing or backend acceptance evidence. The exact prompts and edit history are preserved in [GENERATION-PROMPTS.json](GENERATION-PROMPTS.json).

Actual company templates, paper and letterhead still require calibration against the separately provided quotation-folder examples.
