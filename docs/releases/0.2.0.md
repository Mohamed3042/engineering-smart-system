# Engineering Smart System 0.2.0

This release completes the inbox, project review, file viewer and quotation editor work, including phone layouts. Project and company lists begin compact; details open when selected.

Quotations support company papers, signatory selection, stamp and photo placement on rendered pages, catalog items, project template rules and scoped memory of reviewed corrections. Inbox actions can link messages to projects, create projects and retry attachments. Workflows expose their real triggers and support creation, editing and deletion.

The Windows desktop launcher checks installation and build failures before opening the app. It also verifies the running engine's version and commit, preventing an old background server from being mistaken for the updated installation. Account settings show the interface and engine versions. Source copies without Git report an unknown commit.

Email snapshot imports retain mailbox, message, attachment and enquiry provenance. Same-named attachments from different messages remain separate.

Validation: 638 backend tests passed; the frontend type check and production build passed. The preceding UI acceptance record contains desktop and phone browser captures at [docs/ui-review](../ui-review/INDEX.md). Physical phone testing is not included.

On Windows, update the existing checkout and run `Start.cmd`. Keep `data/` and `backend/.venv/` when updating. Stop the existing launcher with Ctrl+C before restarting the updated engine. Company assets, email evidence and quotations stay in the local ignored data folder and are excluded from this release. Importing an email example does not configure ongoing mailbox synchronization.
