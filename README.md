# Engineering Smart System

UI/UX concept images for a configurable engineering email-to-quotation workspace, using Medmack as the sample company.

**144 independently generated mockups: 72 desktop screens and 72 phone screens.** Every PNG contains one device and one active screen or dialog. There are no collages.

- [Browse every screen](docs/ui-mockups/SCREEN-INDEX.md)
- [Desktop mockups](docs/ui-mockups/Desktop)
- [Phone mockups](docs/ui-mockups/Phone)
- [Exact generation and correction prompts](docs/ui-mockups/GENERATION-PROMPTS.json)
- [Download the repository ZIP](https://github.com/Mohamed3042/engineering-smart-system/archive/refs/heads/main.zip)

The concepts cover onboarding, AI connections, inbox classification, projects, drawings, engineer review, quotations, customers, research, automations, settings, dialogs, and recovery states.

These are generated visual concepts, not an implemented application. Projects, prices, customer records, account states and activity shown in the images are illustrative sample content. The visual direction applies Impeccable Operate principles.
