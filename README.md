# Engineering Smart System

UI/UX concept images for a configurable engineering email-to-quotation workspace, using Medmack as the sample company.

**158 independently generated mockups: 79 desktop screens and 79 phone screens.** Every PNG contains one device and one active screen or dialog. There are no collages.

The concepts cover onboarding, AI connections, inbox classification, projects, drawings, engineer review, quotations, customers, research, automations, settings, dialogs, and recovery states. Version 2 adds requirement revisions, deadline amendments, renewed approval, customer-response tracking, Arabic inspection requests, BOQ evidence and maintenance quotations.

These PNGs are generated visual concepts, not an implemented application. Projects, prices, customer records, account states and activity shown in the images are illustrative sample content. The visual direction applies Impeccable Operate principles.
